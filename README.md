# 🎮 PlayGames

E-commerce de videojuegos desarrollado 100% con PHP vanilla (sin frameworks) como proyecto de la carrera de Diseño y Programación Web en Escuela Da Vinci.

## ✨ Características
- Registro e inicio de sesión de usuarios
- Panel de administración para gestionar [productos / usuarios / pedidos]
- Catálogo de juegos [con carrito de compras, si lo tiene]
- Base de datos relacional en MySQL

## 🛠️ Tecnologías
PHP · MySQL · HTML5 · CSS3 · [JavaScript]

## 🚀 Correr el proyecto en local
1. Instalá [XAMPP](https://www.apachefriends.org/) o similar y levantá Apache y MySQL.
2. Cloná el repo dentro de la carpeta `htdocs`.
3. Importá el archivo `[nombre].sql` en phpMyAdmin.
4. Configurá la conexión en `[archivo de configuración]`.
5. Abrí `http://localhost/playGames`.

## 📚 Qué aprendí
Arquitectura de una aplicación PHP sin frameworks, manejo de sesiones y roles (usuario y admin) y diseño de base de datos relacional.
